# Reproduce the KB snapshot

Requires Node 24 or later.

```sh
npm ci
npm run build
npm run verify
```

The renderer uses mdsvex, Svelte server rendering, the exported components and their data. It writes styled HTML snapshots to `rendered/kb/`. These are static snapshots; explorer controls show their initial state and its computed cases, without client hydration. No service or public web host is required.

The new assessment is `src/routes/kb/incidents/4471-review/+page.svx`; its rendered counterpart is `rendered/kb/incidents/4471-review/index.html`. Its signature is attributed to Jakub Chojnacki and Codex; RenderStamp derives the desk reference from that signature.

`report-evidence.json` records the unique report IDs in each cause. It is regenerated by verification. Counts reflect the supplied export, not a live support system.

The original accepted decision is retained. Reusable component punctuation was adjusted to the author's writing convention. The new page proposes replacing the subject-only merging rule without rewriting the historical decision.
